# 99-inbox — thả thô vào đây

- Tài liệu, CV, transcript họp, email đối thủ, tin nhắn khách… → thả vào đây trước. Không phân loại. **Phân vân → inbox.**
- Rồi bảo Claude: `Đọc 99-inbox/<file>, distill thành 10-work/1-<slug>.md …`
- File ≤3 trang. PDF scan → chuyển text trước.
- Output tạm của skill → `99-inbox/out/`.
