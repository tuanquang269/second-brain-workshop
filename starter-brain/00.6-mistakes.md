# 00.6 — Lỗi đã gặp → luật

> Claude đọc file này trước việc rủi ro. Gặp lỗi mới → Claude tự ghi thêm, không cần hỏi. Lỗi hôm nay = luật ngày mai.

## [2026-08-17] Ghi đè file đang mở trong Obsidian
- **Mistake:** Claude ghi lại `10-work/1-<slug>.md` khi tab đó đang mở → Obsidian tạo bản "conflict" 0 byte.
- **Root cause:** Obsidian giữ file trong bộ nhớ; ghi từ ngoài trong lúc đang sửa.
- **Fix:** đóng tab trước khi chạy skill ghi đè; xoá file 0 byte.
- **Rule:** *Claude ghi, rồi bạn mở.* Không sửa tay trong lúc skill đang chạy.
