# 00.7 — Skill của tôi

> Skill = 1 file `SKILL.md` dạy Claude làm 1 việc lặp lại. Nằm ở `.claude/skills/<tên>/SKILL.md`. Chạy bằng `/<tên>`.
> **Không có dòng ở đây = skill không tồn tại.** Skill mới → thêm 1 dòng, cùng phiên.

| Skill | Gọi bằng | Input → Output |
|---|---|---|
| hello-brain | `/hello-brain` | đọc `00.4-index.md` → `99-inbox/hello.md` (3 điều não này biết) |
| interview-scorecard-lite | `/interview-scorecard-lite prep <cv> role=<vị trí>` · `score <slug>: <debrief>` | CV → `40-hr/candidates/<slug>.md` + câu hỏi; debrief → 5 điểm, xếp hạng trong `candidates.base` |
| meeting-summary | `/meeting-summary <transcript>` | transcript → `96-daily/meeting-<ngày>.md` (quyết định · việc-ai-hạn · rủi ro · email draft) |
| work-orders-lite | `/work-orders-lite <danh sách việc>` | 5–10 việc → `96-daily/work-orders-<ngày>.md` (Musk 5 bước) |
| obsidian-markdown | tự kích hoạt khi viết ghi chú | cú pháp Obsidian: wikilink, callout, properties |
| obsidian-bases | tự kích hoạt khi đụng `.base` | tạo/sửa bảng sống `.base` |
| obsidian-cli | tự kích hoạt khi cần điều khiển Obsidian | cần Obsidian đang mở + bật CLI trong Settings |
| json-canvas | tự kích hoạt khi cần vẽ sơ đồ | file `.canvas` (mind map, flow) |
